# 02_Python_EDA — Python learning steps

Run these from the main `northstar-project` folder in Command Prompt:

1. `python 02_Python_EDA\01_create_database.py` — make the sample SQLite database.
2. `python 02_Python_EDA\02_export_sql_to_csv.py` — query SQLite and create `reports\orders_for_powerbi.csv`.
3. `python 02_Python_EDA\03_check_data.py` — missing values, duplicates, basic statistics.
4. `python 02_Python_EDA\04_revenue_tables.py` — group sales by region and product.
5. `python 02_Python_EDA\05_make_eda_charts.py` — create four charts.

`seed.py` is called by step 1. It contains sample data generation. Results go in the main `reports` folder.
