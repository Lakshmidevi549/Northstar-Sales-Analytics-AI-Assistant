# 03_PowerBI — Power BI report

1. Run Python steps 1–5 from the main project README.
2. Open Power BI Desktop → **Get data** → **Text/CSV**.
3. Select `reports\orders_for_powerbi.csv` and choose **Load**.
4. Add a revenue card, a line chart (date and revenue), a region pie chart, and a product bar chart.
5. Add date and region slicers. Save your report in this folder as `northstar-sales.pbix`.

This folder holds your Power BI report. Python makes the CSV that Power BI reads.
